A private LLM gateway, running in your browser

The gateway puts per-app API keys and SSO roles, rate limits, PII redaction, a tamper-evident audit log and permission-aware, cited document Q&A in front of a local model server (Ollama or vLLM). This page runs that gateway's Python modules so you can try the controls without installing anything.

Real repo codeThe gateway's own store.py, auth.py, identity.py, audit.py, redact.py, rag.py and backends.py are fetched from this repository and run unmodified in Pyodide (Python on WebAssembly).
Nothing leaves the pageKeys, the SQLite database, documents and the audit log live in this tab's memory. There is no server behind this demo. Reload to start over.
No LLM in demo modeAnswers are the best-matching sentences from the retrieved passages, with citations. Embeddings are hashed bag-of-words vectors, not a neural model. The deployed gateway uses Ollama or vLLM for both.

5Identity, roles and permission-aware retrieval

Switch between people (SSO tokens) and applications (API keys). Two sample documents carry access lists. The gateway decides what each caller may read before passages are loaded or ranked, so hidden documents never show up in answers, citations, injection flags or counts.

Pick someone.

Runs gateway/identity.py principal_for_claims (groups → roles), can_read_collection, can_read_document, and gateway/rag.py access_for, candidates (ACL filter in SQL), retrieve. Token personas are built from claims in the page: the JWT signature check (PyJWT against the identity provider's JWKS) runs only on the server. See ADR 0005.
