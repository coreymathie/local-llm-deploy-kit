# Member Identity Verification

This standard applies to branch, contact-center and digital staff.

## Opening an account

New members provide one government-issued photo ID and a Social Security or Individual Taxpayer Identification Number. Ask for a secondary document, such as a utility statement dated within 60 days, only when the address on the ID is not current.

## Phone and digital channels

Before discussing an account over the phone, verify the caller with a one-time code sent to the mobile number on file. Caller ID alone never proves identity. Staff must never ask a member to read back a full card number or online banking password.

## In-branch withdrawals

Ask for photo ID before any cash withdrawal when the teller does not know the member. Compare the signature on file for withdrawals over $5,000.
